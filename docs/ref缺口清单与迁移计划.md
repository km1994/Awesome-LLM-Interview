## 0. 一句话结论

两个仓库**不是同一份内容的不同版本**，而是两个定位不同的项目：

| | 源仓库（WeThinkIn） | 本仓库（km1994） |
|---|---|---|
| 定位 | **全栈 AIGC 求职平台**：技术 + 求职 + 职业生涯 + 课程 + 社区运营 | **考点化面试题库**：题 + 答案 + 避坑 |
| 组织方式 | 按**知识板块**（24 个） | 按**考点专题**（37 个）+ **题库**（7 个） |
| 题目形态 | 概念讲解式长文 + 大厂实战题库 | 统一三段结构：考察点 / 得分项 / 作答要点 |
| 规模 | 约 **15.8 万行** | 约 **5.7 万行** |
| 强项 | 广度（图像 / 视频 / 数字人 / 具身 / 传统 CV / 计算机基础 / 求职全链路） | 深度（RAG 160 / Agent 100 / RL 120 / Hermes 100 / Loop 100 / GraphRAG 100 / 检测 100） |
| 弱项 | 逐题拆解、答题结构、新范式题库（Harness / Loop / GraphRAG） | 生成式视觉、具身智能、传统基础学科、大厂题库、求职层 |

**结论**：本仓库不需要"搬运"源仓库，需要的是**补广度缺口 + 把源仓库的概念式内容改造成本仓库的三段结构**。源仓库的精华有 4 类：① 生成式视觉与具身智能板块 ② 40 家大厂题库 ③ 求职与职业生涯层 ④ 社区共创运营机制。

## 5. 合规红线（**必读，违反会毁掉仓库**）

### 5.1 授权事实

| 项 | 事实 |
|---|---|
| 源仓库许可证 | **GPL-3.0**（`LICENSE` 674 行，GNU GPL v3） |

### 5.2 因此迁移必须遵守

1. **不复制正文**。只提炼考点、机制、权衡维度、公式与图示思路，用自己的话、按本仓库三段结构重写。逐句改写同样算抄袭，判据是"能否脱离原文独立成篇"。
2. **不搬运图片**。源仓库 `imgs/` 与各板块配图受 GPL-3.0 / 原作者版权约束，一律自绘示意图。
3. **大厂题库只取题目维度**。保留「公司 / 岗位 / 轮次 / 题目 / 考察方向」，答案必须重写。涉 NDA 的保密内容一律不迁。
4. **剔除个人宣传元素**。源仓库内容含作者署名、公众号、知识星球二维码、内推小助手微信号等，迁移时全部剔除。
5. **标注来源与核验日期**。凡是引用源仓库的数据、模型版本、薪资区间、时间节点，都要标来源 + 日期，明确"时效信息，可能已变化"。
6. **补 LICENSE**。本仓库当前无许可证，建议尽快明确（MIT / Apache-2.0 / CC-BY-NC-4.0 按定位选）。同时注意：一旦接受了 GPL-3.0 代码/文本，整个仓库的许可选择会被传染性约束。**这正是不能搬原文的另一个硬理由。**
7. **每条迁移内容做一次查重自检**。建议采用与源文不同的章节切分方式 + 不同的题目顺序，并在提交信息中记录"来源：WeThinkIn/AIGC-Interview-Book 某板块，已重写"。
