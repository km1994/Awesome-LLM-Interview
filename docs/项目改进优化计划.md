# 项目改进优化计划

> 对象：`km1994/AIGC-Interview-Book`《大模型面试宝典》
> 版本：v1.0 ｜ 制定日期：2026-09-29
> 依据：`docs/质量与增长改进清单.md`（体检报告）+ `docs/ref缺口清单与迁移计划.md`（内容迁移计划）

---

## 0. 计划概览

### 0.1 现状基线

| 维度 | 现状 |
|---|---|
| 考点规模 | 1000+，含 7 个深专题（RAG/Agent/RL/Hermes/Loop/GraphRAG/检测） |
| 内容定位 | 考点化题库，统一三段结构（考察点/得分项/作答要点），差异化清晰 |
| 引流 | 公众号 + 知识星球 + 优惠券，已有 |
| 分发 | 无独立网站，纯 GitHub md 仓库 |
| 持续产出 | 无（面经/大厂题库/季报均"计划中"） |
| 社区机制 | 仅一份简版 CONTRIBUTING |

### 0.2 目标（3 个月内）

1. 有一个可分享、可搜索的**在线阅读站**
2. **真实面经 + 大厂题库**上线，兑现定位
3. 跑通**共创机制**，发布**首期季度趋势报告**
4. Star 数翻倍、公众号/星球有稳定的选题来源

### 0.3 三条原则

1. **借运营手段，保内容定位**——学 ref 项目的运营，不变成第二个教程站
2. **先分发，后内容**——先让仓库能被看见，再补内容长尾
3. **每阶段有验收标准**——做完能检查，而不是"感觉差不多了"

## 1. 分阶段路线图

### Phase 0：基础设施（第 1–2 周）—— 让仓库像正式产品

| # | 任务 | 产出 | 验收标准 |
|---|---|---|---|
| 0.1 | 搭建在线阅读站 | docsify 或 VitePress 站点 + GitHub Pages + 国内加速域名 | 手机端可读、可搜索、分享有落地页 |
| 0.2 | README 首屏重做 | hero 封面图 + 一句话定位 + "你将收获什么" + 内容完成度表 + 徽章 | 新读者 30 秒内看懂"这是什么、对我有什么用" |
| 0.3 | 统一目录导航 | 站点侧边栏合并 `docs/` 100 题 + 编号专题 + 新专题三类入口 | 任意一篇能一键回到首页和同类专题 |
| 0.4 | 内容完成度表 + Backlog | PROJECT_SUMMARY.md + BACKLOG.md（脚本自动生成） | 读者能看出"哪些能直接背、哪些还没写完"；贡献者知道该帮什么 |

**关键决策**：选 docsify 还是 VitePress？
- docsify：零构建，改 md 即生效，最快
- VitePress：SEO 更好、更现代，但要构建步骤

推荐 **先 docsify 跑起来，后续有余力再迁 VitePress**。

### Phase 1：内容兑现定位（第 3–4 周）—— 形成可传播的差异化内容

| # | 任务 | 产出 | 验收标准 |
|---|---|---|---|
| 1.1 | 真实面经复盘 | `docs/interview_reports/` 下 5–10 条结构化面经（公司/岗位/轮次/题目/复盘五要素） | 素材来源明确、去敏、题目与本仓库专题互链 |
| 1.2 | 大厂题库 Top10 | 腾讯/字节/阿里/百度/美团/拼多多/小红书/快手/华为/蚂蚁，各一个文件 | 命中"XX 面经""XX 面试题"搜索词 |
| 1.3 | 求职指南 + 学习路线 | 1 条主线路线图（校招/社招二选一先做）+ 简历要点 | 从"刷题"延伸到"上岸" |
| 1.4 | 经典专题答案展开 | 分批把 37 个经典专题的题单补成完整答案 | 每批至少 3 个专题，沿用三段结构 + 去 AI 味自检 |

**素材来源**：`ref/面经汇总_2026/` 已归档的 4 篇知乎面经 + 5 个线上仓库（`hello-agents/Extra-Chapter`、`AgentGuide/docs/04-interview` 等），全部已完成重叠度扫描（0 重复）。

### Phase 2：持续产出机制（第 5–6 周，之后常态化）—— 启动传播飞轮

| # | 任务 | 产出 | 验收标准 |

| 2.4 | 维护节奏声明 | README 加"更新节奏"（持续/月/季/年） | 让读者知道仓库在滚动更新 |

## 2. 优先级矩阵

按"影响力 × 成本"排，先做左上角（高影响、低成本）：

| | 低成本 | 高成本 |
|---|---|---|
| **高影响** | 🥇 网站(0.1)、README 重做(0.2)、面经(1.1)、大厂题库(1.2) | 🥈 共创机制(2.1)、季报(2.3) |
| **低影响** | 完成度表(0.4)、Backlog(0.4)、维护节奏(2.4) | 双语(4.x)、价值判断台账(4.x) |

## 4. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 网站搭建踩坑、拖延 | 卡住整个 Phase 0 | 先 docsify 最简版上线，别追求完美 |
| 面经/题库有版权或隐私风险 | 法律风险 | 只保留题目维度、答案重写、去敏、标注来源；沿用已有的三层查重自检 |
| 季报数据不足、写不出来 | Phase 2 卡壳 | 首期就用已归档的知乎面经 + AgentGuide，样本少就标注"样本有限" |
| 单人维护精力不足 | 计划停滞 | 共创机制本身就是在借力；把"维护节奏"定得现实（季报而非月报起步） |
| 内容越做越散 | 丢失定位 | 每个新专题过一遍"考点化三段结构"的准入检查 |
